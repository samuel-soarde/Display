# Estudo de Display — HTML & CSS

Projeto criado para estudar a propriedade `display` do CSS e entender seus principais valores e casos de uso na construção de layouts.

## 📚 Sobre o projeto

Este projeto é um exercício prático para compreender como diferentes valores de `display` alteram o comportamento, posicionamento e organização dos elementos HTML.

Durante o estudo, são explorados valores como:

- `block`
- `inline`
- `inline-block`
- `flex`
- `grid`
- `none`

A proposta é observar, na prática, como cada tipo de `display` funciona e em quais situações ele pode ser mais adequado.

## 🎯 Objetivos

- Entender o comportamento dos principais valores de `display`.
- Comparar `block`, `inline` e `inline-block`.
- Praticar layouts com `flex`.
- Praticar layouts com `grid`.
- Entender como `display: none` afeta os elementos.
- Desenvolver uma base sólida para criação de layouts com CSS.
